# Rust Learning

This repository is a small Rust practice project created to explore the basics of the Rust programming language, including project setup, compilation, and running simple programs. It serves as a hands-on learning workspace for understanding Rust syntax, ownership, borrowing, and the development workflow used in real-world Rust applications.

The project currently contains a minimal `main.rs` example and is intended to grow over time as new language concepts and exercises are added.
