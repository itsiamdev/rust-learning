# Rust Learning

This repository is a beginner-friendly workspace for learning Rust through small, focused examples. It is a Rust 2024 Cargo project: the runnable program in `src/main.rs` prints a developer profile and demonstrates variable declarations, mutability, basic scalar types, and formatted output with `println!`.

The `lessons/` directory contains numbered standalone source files organized around introductory topics such as “Hello, world!”, variables and data types, operators, and `if`/`else` control flow. These examples are kept separate from the Cargo entry point so each lesson can be explored independently. The project is intended to grow as more language concepts and exercises are added.

## Lessons

1. [Hello, World!](lessons/01-hello-world.rs) — print your first message.
2. [Variables and Data Types](lessons/02-variables-and-data-types.rs) — declare variables, use mutability, and explore basic types.
3. [Operators](lessons/03-operators.rs) — use arithmetic operators.
4. [If/Else](lessons/04-if-else.rs) — practice conditional logic and `if` expressions.
